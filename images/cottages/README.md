Les vignettes sont recadrées en 4:3 par le CSS (`aspect-ratio` + `object-fit: cover`),
les formats portrait et paysage s'affichent donc de façon homogène.

Pour remplacer une image : garder le même nom de fichier, ou mettre à jour le `src`
correspondant dans `index.html` (section `#work`).
